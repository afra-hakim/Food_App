🚀 Features

Browse Menu: Users can view available food items and their prices.

Add to Cart: Customers can select food items and add them to their cart.

Remove from Cart: Users can remove items from the cart before placing the order.

Place Orders: Customers can confirm and place their food orders easily.

Order Summary: Displays selected items and the total price before checkout.

Simple and User-Friendly Interface: Easy navigation for smooth ordering experience.

Technologies Used

Python
Tkinter
